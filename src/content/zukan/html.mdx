## 「あいまいだが面白い」と書かれた紙から

1989年、スイスの研究所 CERN で働いていたティム・バーナーズ＝リーが、1本の提案書を書きました<Cite n={1} />。研究所の中に散らばった情報を、互いに結びつけて辿れるようにしよう、という内容です。

上司はその紙に「Vague but exciting（あいまいだが面白い）」と書き込みました。却下でも承認でもない、この一言から Web が始まります。

1991年には最初のWebサイトが公開されました。そのページは、いまも同じ場所で読めます<Cite n={3} />。30年以上前の文書が、いまのブラウザでそのまま開く。これは HTML が後方互換を保ち続けてきた結果でもあります。

{/* block: naming */}
## 名前の由来：ハイパーなテキストに、印を付ける言語

HTML は HyperText Markup Language の頭文字です<Cite n={2} />。

- **HyperText（ハイパーテキスト）** — 別の文書へ飛べる文書。この「飛べる」がWebの核心です
- **Markup（マークアップ）** — 文章に印を付けること。もとは印刷所で、原稿に「ここは見出し」と赤を入れる作業を指しました
- **Language（言語）** — その印の付け方の決まり

つまり HTML は「飛べる文章に、ここは何かという印を付けるための決まり」です。プログラミング言語ではなく、印の付け方の約束です。

{/* block: analogy */}
## たとえ話：原稿に入れる赤字

紙の原稿に「ここは大見出し」「ここは引用」と赤を入れる作業を思い浮かべてください。赤を入れる人は、文字の大きさや色までは決めません。それは印刷所の仕事です。

HTML も同じです。`<h1>` と書くのは「ここは一番大きな見出しです」という意味の指定であって、「24ポイントの太字で」という指定ではありません。見た目は [CSS](/zukan/css/) が決めます。

この分担を知らないまま HTML で見た目を整えようとすると、必ず行き詰まります。

## 最初に覚える3つ

| 書き方 | 意味 |
|---|---|
| `<h1>見出し</h1>` | ここは見出しです |
| `<p>文章</p>` | ここはひとつの段落です |
| `<a href="行き先">文字</a>` | ここを押すと行き先へ飛びます |

3つめがWebそのものです。文書と文書が互いに飛べること。これだけが、ほかの文書形式との決定的な違いでした。

## あなたとの関係

いま読んでいるこのページも HTML です。ブラウザで右クリックして「ページのソースを表示」を選ぶと、中身が見えます。

メールの署名が崩れる、社内システムの入力欄が妙な動きをする。こうしたとき、HTML の形が分かると原因の当たりがつきます。

## ネットでの扱われ方

「HTML はプログラミング言語か」という論争が、定期的に燃えます。

厳密には違います。条件分岐も繰り返しもなく、計算をしません。ただ、この議論が繰り返されるのは、線引きそのものより「できる人・できない人」の線引きに使われがちだからです。名乗り方を気にするより、書けることのほうが実利があります。

{/* block: misunderstanding */}
## よくある誤解：見た目を整えるための言語

違います。HTML が指定しているのは意味です。

`<h1>` が大きく表示されるのは、ブラウザが初期設定でそう表示しているだけです。この意味づけは、目の見えない人が使う読み上げソフトにとっては生命線になります。見出しとして印が付いていれば飛ばし読みができますが、ただ大きい文字では区別がつきません。

{/* block: firststep */}
## 今日5分でできること

メモ帳を開いて次の3行を書き、`test.html` という名前で保存してください。

```html
<h1>はじめてのページ</h1>
<p>これは段落です。</p>
<a href="https://info.cern.ch/hypertext/WWW/TheProject.html">世界初のサイトへ</a>
```

ダブルクリックするとブラウザで開きます。リンクを押すと、1991年に戻れます。
