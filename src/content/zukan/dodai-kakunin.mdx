## なぜ型の確認用ページが必要なのか？

図鑑は35ページになります。もし型がずれたまま35ページ書いてしまうと、直すときに35倍の手間がかかります。だから先に1ページだけ作り、全部の部品が正しい場所に出るかを確かめます。

出典の番号はこう置きます<Cite n={1} />。番号は frontmatter の `sources` と突き合わされ、片方にしか無ければ検査が止めます。

{/* block: naming */}
## 「土台」とは何を指すのか？

ここでは、ページの枠組みそのものを指します。図鑑カード、レーダーチャート、目次、出典欄、今日のひとこと。これらが自動で出てくる仕組みが土台です。

## たとえ話

家を建てるときの基礎と同じです。基礎が傾いていると、どの部屋もまっすぐ建ちません。

## 図解は説明文のすぐ隣に置く

図解は本文の途中から呼び出せます。説明と図が離れないようにするためです。

## 最初に覚える3つ

- `npm run dev` — 開発サーバーを立ち上げる
- `npm run check` — ページの型を検査する
- `npm run build` — 検査を通してから公開用に組み立てる
