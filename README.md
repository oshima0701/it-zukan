# IT技術図鑑

個人の学習記録です。

プログラミングを始めたばかりの人向けに、IT技術を図鑑の形でまとめています。
各技術の誕生年・生みの親・出身地・名前の由来を軸に、1項目1ページ。

- 設計: [docs/設計書.md](docs/設計書.md)
- 依頼の原文: [docs/指示書.md](docs/指示書.md)

## 動かす

```
npm install
npm run dev      # 開発サーバー
npm run check    # ページ構成の検査
npm run build    # 検査してからビルド
```

## 項目を増やす

`src/content/zukan/` に `.mdx` を1つ足すだけです。
図鑑カード・町の地図・年表・世界地図・人物相関図には自動で現れます。
